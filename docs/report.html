Before you write

  • Search the open issues first. If yours is there, add a thumbs up or a comment.
  • Check the questions and fixes.
  • One problem per report makes it faster to fix.

What helps

App version
Neat Nest, Settings, at the bottom.
Phone model and Android version
Android settings, About phone.
Which view
Text, Tree, Table, Compare, the filter, find and replace, a widget or Settings.
Steps
What you did, one step per line.
A small file that shows it
Only if it holds nothing private.

Issues on GitHub are public. Never paste private data, keys or passwords, and crop screenshots.
